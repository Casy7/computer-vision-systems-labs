# Лабораторна робота №5: Стереопара: ректифікація, диспаратність, глибина

## Варіант та вхідні дані
- **Варіант 2:** зйомка стереопари однією каліброваною камерою (Google Pixel 5) з горизонтальним зміщенням $B = 10$~см ($100.0$~мм) без повороту.
- **Вхідні кадри:** `lab05/data/photo_left.jpg`, `lab05/data/photo_right.jpg` ($4032 \times 2268$, 16:9).
- **Робоча роздільна здатність:** `WORK_SCALE = 0.5` ($2016 \times 1134$~пк).
- **Внутрішні параметри камери:** завантажено з `lab02/camera_params.yml` та адаптовано під симетричний вертикальний кроп 16:9 ($\Delta y = 378$~пк) і масштаб $0.5$.

## Структура проєкту
- `src/common.py` -- завантаження стереопари, адаптація матриці $K$, взаємне зіставлення SIFT.
- `src/part_a_b.py` -- Частини A та B (Кроки 1--6): оцінка мікроповороту камери через істотну матрицю $E$, стереоректифікація `cv2.stereoRectify`, візуальна та кількісна перевірка горизонтальності епіполярних ліній ($|y_L - y_R| < 1$~пк).
- `src/part_c.py` -- Частина C (Кроки 7--9): порівняння `StereoBM`, `StereoSGBM` та `StereoSGBM + WLS`, повний факторний експеримент на сітці 36 комбінацій параметрів (`numDisparities`, `blockSize`, `uniquenessRatio`).
- `src/part_d.py` -- Частина D (Кроки 10--12): обчислення метричної глибини $Z = f \cdot B / d$ та через `cv2.reprojectImageTo3D`, верифікація відстаней до 7 об'єктів сцени, генерація 3D-хмари точок `results/point_cloud.ply`.
- `src/part_e.py` -- Частина E (Крок 14): кількісний та візуальний аналіз 4 зон систематичних помилок стереозіставлення.
- `report/report.tex`, `report/title.tex`, `report/tables.lua` -- код звіту для компіляції через `lualatex`.
